# SDRAM - 基本原理

## 简介
同步动态随机存储器（Synchronous Dynamic Random Access Memory）
- 同步：命令与数据统一在CLK上升沿有效
- 动态：依靠电容存储数据，需要周期性刷新（充电）
- 随机：给出行列地址可以直接访问数据

## SDR与DDR
- SDR（Single Data Rate）：一个时钟周期边沿传输一个数据
- DDR（Double Data Rate）：一个时钟周期的两个边沿都传输数据
提升：提高时钟频率、增加预取长度、降低工作电压、增大内存容量

## SDRAM参数解释
- 核心频率：内存cell阵列的刷新频率，内存的真实运行频率
- 时钟频率：I/O Buffer的传输频率
- 数据传输率：数据传输的频率（通常是时钟频率的两倍）
- BL：突发长度，读/写一次地址后，自动连续传输的长度（最大为一页，代表一整行）
- 预取：即预加载，I/O控制器请求前，已将多被于芯片位宽的数据存入存储单元（并行方式读取，接口串行输出）
- CL值：CAS潜伏期，读命令发出首个有效数据输出的时钟周期数，只读
- Bank：芯片内独立的存储的存储单元

## SDRAM存储单元工作原理
SDRAM内部可看作一个表格，拥有：
- 行（ROW）
- 列（Colum）
- 存储单元：存储Nbit数据
- 寻址规则：先选行（*行激活），再选目标列，进行读或写
