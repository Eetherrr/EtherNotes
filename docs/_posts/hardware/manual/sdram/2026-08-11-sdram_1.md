# SDRAM 基本原理

## 一、简介

同步动态随机存储器（Synchronous Dynamic Random Access Memory）：

- **同步（Synchronous）**：命令与数据统一在 CLK 上升沿有效，所有操作与系统时钟同步
- **动态（Dynamic）**：依靠电容存储电荷，电荷会随时间泄漏，需要周期性刷新（充电）
- **随机（Random）**：给出行列地址即可直接访问任意存储单元，无需顺序遍历

## 二、SDR 与 DDR

|          | SDR                        | DDR                          |
| -------- | -------------------------- | ---------------------------- |
| 全称     | Single Data Rate           | Double Data Rate             |
| 数据速率 | 每时钟周期一个边沿传输一次 | 每时钟周期两个边沿各传输一次 |
| 典型频率 | 100 ~ 166 MHz              | 200 ~ 400+ MHz               |
| 供电电压 | 3.3V                       | 2.5V / 1.8V                  |

性能提升途径：提高时钟频率、增加预取（Prefetch）长度、降低工作电压、增大 Bank 数量和内存总容量。

![SDR vs DDR 对比](https://eetherrr.github.io/EtherNotes/assets/images/sdram_1.png)

## 三、关键参数速查

| 参数                   | 含义                                                                                         |
| ---------------------- | -------------------------------------------------------------------------------------------- |
| **核心频率**           | 内存 Cell 阵列的工作频率，即 SDRAM 的"真实"运行频率                                          |
| **时钟频率**           | I/O Buffer 的传输频率（CK 引脚上的时钟）                                                     |
| **数据传输率**         | 数据总线的等效传输频率，DDR 通常是时钟频率的 2 倍                                            |
| **BL（Burst Length）** | 突发长度——发一次地址后自动连续传输的字数。最大为"全页"（一整行）                             |
| **Prefetch（预取）**   | 预加载机制——I/O 控制器请求前，已从阵列并行取出多于芯片位宽的数据，再通过接口串行输出         |
| **CL（CAS Latency）**  | CAS 潜伏期——读命令发出到首个有效数据输出所需的时钟周期数。仅影响读，写命令数据与命令同拍送入 |
| **Bank**               | 芯片内独立的存储单元组。多个 Bank 可同时保持激活，实现交错访问、隐藏预充电延迟               |

## 四、存储单元原理

### 4.1 1T1C 基础存储单元

SDRAM 的最小存储单元由一个晶体管（MOSFET）和一个电容组成，称为 **1T1C 结构**：

- **电容**：存储电荷，有电荷 = 逻辑 1，无电荷 = 逻辑 0
- **晶体管**：充当开关，控制电容与位线（Bit Line）的连接

**写入过程**：

1. 字线（Word Line）拉高，晶体管导通
2. 位线上施加目标电压（高/低电平）
3. 电容被充电或放电，数据写入
4. 字线拉低，晶体管截止，电容与外界隔离

**读取过程**：

1. 位线预充电到 VDD/2
2. 字线拉高，晶体管导通
3. 电容与位线共享电荷，位线电压产生微小偏移
4. 灵敏放大器（Sense Amplifier）检测并放大偏移到满摆幅
5. 读取是**破坏性**的——灵敏放大器在放大信号的同时**回写**数据到电容

> 电容存在漏电流，存储的电荷会在几十毫秒内泄漏殆尽，因此**必须周期性刷新**。

### 4.2 存储阵列

存储单元排列成行列矩阵。以 3x3x1bit 为例（实际典型 SDRAM 为 8192 行 x 512 列 x 16 位）：

- **字线（WL）**：控制一整行，选中时同行所有单元全部打开
- **位线（BL）**：每列共享一条，传输数据至灵敏放大器
- **灵敏放大器（SA）**：每列一个，锁存整行数据

**行激活（Row Active）**：选中一条字线 → 该行所有存储单元的晶体管导通 → 各列电容与对应位线共享电荷 → SA 锁存整行数据。此时整行数据暂存在 SA 中，后续列选择只需从 SA 中直接读取。

![3x3 存储矩阵示意](https://eetherrr.github.io/EtherNotes/assets/images/sdram_3_array.png)

### 4.3 L-Bank 逻辑存储块

每个 Bank 是一个独立的存储阵列（含自身的行/列译码器、SA、I/O 门控）。典型 SDRAM 有 4 个 Bank。

**多 Bank 的意义——隐藏预充电延迟**：

- 单 Bank：读完一行 → 预充电（tRP 约 2~3 个时钟周期）→ 激活另一行 → 等待 tRCD → 才能读写。预充电期间总线空闲
- 多 Bank：Bank A 读数据的同时，Bank B 正在预充电；Bank A 预充电时，Bank C 已经可以开始读——流水线化，消除空闲

> 这项技术称为 **Bank Interleaving（Bank 交错）**，是 SDRAM 实现高带宽的核心机制。
