# 项目概览

本项目基于 awc_c4mb_v11 开发板，使用 OV5640 图像传感器捕获图像并通过RGB转灰度、高斯滤波、索贝尔算子等算法提取图像边缘，并通过VGA接口显示到屏幕

## 硬件资源
- FPGA: EP4CE6F17C8
- SDRAM: H57V2562GTR-75C
- Camera: OV5640
