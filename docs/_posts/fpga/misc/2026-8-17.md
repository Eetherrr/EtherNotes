# 亚稳态
- 产生原因：
	- 未满足触发器的建立时间和保持时间，在采样信号的边沿时，信号仍在变化，并且会级联传播，危害整个电路
- 如何避免：
	- 降低系统时钟频率
	- 用反应更快的触发器
	- 引入同步机制
	- 改善时钟质量，用边沿变化更快的时钟

# 同步复位与同步复位
## 同步复位
- 优点
	- 抗干扰性强
	- 利于静态时序分析
	- 利于周期仿真
- 缺点
	- 器件不支持，需要额外资源实现
	- 依赖时钟，若时钟出问题则无法复位
	- 对复位信号的脉宽有要求，可能需要多个时钟周期，难以保证触发器时序
## 异步复位
- 优点
	- 延迟低、复位快
	- 不依赖时钟
- 缺点：
	- 可能产生亚稳态
	- 
## 优化
	采用异步触发、同步释放
