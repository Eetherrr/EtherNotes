# 分类
- 单口RAM：**只有一个窗口**，寄件和取件都得排同一个队，不能同时进行。
- 真双口RAM： **两个独立窗口**，每个窗口都能寄件也能取件，两边可同时干活互不干扰。
- 伪双口RAM：**两个专用窗口**，一个窗口**只能寄件（只写）**，另一个窗口**只能取件（只读）**，分工明确。

# 硬件结构
|类型|端口A|端口B|读写并发能力|
|---|---|---|---|
|**单口RAM**|1套地址线 + 1套数据线（输入输出复用）|**无**|**不能同时读写**。必须在同一时钟下分时操作|
|**真双口RAM**（True Dual Port）|1套地址线 + 1套**独立**读数据线 + 1套**独立**写数据线（可同时读写）|1套地址线 + 1套**独立**读数据线 + 1套**独立**写数据线（可同时读写）|**可以**。A端口和B端口**各自独立**进行读或写（甚至同时写不同地址）|
|**伪双口RAM**（Simple Dual Port）|**专用写端口**：地址线 + 写数据线 + 写使能|**专用读端口**：地址线 + 读数据线 + 读使能|**可以**。写端口持续写入，读端口持续读出，**两边的时钟和地址完全独立**（但读只能读，写只能写）|

> **注意**：这里的“真/伪”是Xilinx（AMD）和Intel（Altera）官方IP核的常用术语。面试时提到“Simple Dual-Port RAM”即指伪双口。
